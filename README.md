# Feuerwehrjugend – Wissenstest Trainer

Diese Web-App wurde erstellt, um Mitglieder der Feuerwehrjugend beim Lernen und Üben für den Wissenstest zu unterstützen.

## 🚒 Funktionen
- Lernen-Modus (alle Fragen)
- Prüfungs-Modus (10 zufällige Fragen)
- Automatische Bewertung
- Erklärung bei jeder falschen Antwort
- Fortschrittsanzeige
- Moderne Smartphone-Optimierung

## 📁 Dateien
- **index.html** – Haupt-App (Fragen, Logik, Design)
- **manifest.json** – App-Konfiguration (für spätere PWA-Funktion)
- **icon.png** – App-Symbol
- **README.md** – Projektbeschreibung
